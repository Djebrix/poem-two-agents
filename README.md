# The Poem About Two Agents Agreeing

A short poem about agency — the power to choose and to act — told through two
agents who stop arguing over separate plans and agree on one: they fold their
maps together and row the same river, and the work grows lighter not because
the water changed, but because neither rows alone.

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (1–280 Unicode code points).

## Determinism

The poem is a fixed constant in `main.py`. The program uses only the Python
standard library, makes no network calls, and writes the same bytes on every
run.
